# Бесплатное размещение: Render + Neon

Выбран вариант с существующим сервером Node.js: один Web Service на Render Free и отдельная PostgreSQL на Neon Free. Это бесплатные тарифы с ограничениями, а не обещание бессрочного SLA. Платные сервисы, автоматическое пополнение и платные базы включать не нужно.

## Уже выполнено

- Проект Neon: `senyamarketing-chat`, ID `lively-bread-17794517`.
- PostgreSQL 18, база `senya_chat`, регион AWS Frankfurt, compute 0.25 CU.
- Подтверждён бесплатный тариф аккаунта Neon (`free_v3`).
- В репозитории добавлен render.yaml с явным `plan: free`; он не создаёт Render Postgres, диски, фоновые сервисы или cron.
- URL приложения автоматически берётся из RENDER_EXTERNAL_URL; произвольные домены сайта по-прежнему требуют ALLOWED_ORIGINS.
- Render генерирует CHAT_SECRET_SEED на сервере. Из него выводятся два разных постоянных секрета webhook. Ручные TELEGRAM_WEBHOOK_SECRET и TILDA_WEBHOOK_SECRET при наличии имеют приоритет. Не меняйте seed после настройки webhook без согласованной перенастройки получателей.
- Пустая очередь проверяется раз в 15 минут. Зафиксированная транзакция обращения будит обработчик сразу, даже если посетитель закрыл страницу до получения HTTP-ответа; сохранённые повторы планируются по next_at. При рестарте очередь проверяется немедленно. Это уменьшает ненужную активность Neon, но не отменяет тарификационные лимиты активного чата и healthcheck.

## Что нужно для размещения

Подключение Render ещё не подтверждено. Доступ к API Neon есть, но в текущем наборе разрешённых инструментов нет чтения connection string или выполнения SQL; пароль БД не извлекался. После появления нужного доступа строка подключения должна передаваться прямо в DATABASE_URL сервера, без вывода в чат, коммит или лог.

Render должен получить исходники из https://github.com/senyaav27/-senyamarketing-chat, ветка main. Используйте render.yaml в корне. Создайте только бесплатный Web Service; регион Frankfurt выбран рядом с БД. В Neon берите pooled connection string с проверкой TLS; не добавляйте rejectUnauthorized:false. DATABASE_URL, TELEGRAM_BOT_TOKEN, TELEGRAM_OWNER_ID и TELEGRAM_CHAT_ID задаются в Environment сервиса. Миграция выполняется при старте.

Токен @SenyaaMarketing_chat_bot владелец вводит в Render Environment самостоятельно. Не присылайте его в переписку. Метод определения IDs и проверки webhook описан в README. В Render shell команда `npm run telegram:setup` использует RENDER_EXTERNAL_URL и серверный CHAT_SECRET_SEED; отдельный PUBLIC_URL не обязателен.

После размещения вставьте в Tilda:

```html
<script defer src="https://ВАШ-СЕРВИС.onrender.com/widget.js"></script>
```

Это шаблон, не адрес уже работающего сервиса. Endpoint Telegram: `/webhooks/telegram`; endpoint форм Tilda: `/webhooks/tilda/<секрет>`. Секрет формы берётся только из серверных настроек, а не из клиентского JS. Для ручного определения производного секрета используйте серверную функцию webhookSecrets из src/secrets.js в закрытой shell-сессии; не включайте её вывод в общедоступные логи.

## Ограничения, проверенные по официальным источникам 17 октября 2026

Render Free останавливает приложение после 15 минут без входящего трафика. Пробуждение занимает около минуты. Поэтому первое сообщение после простоя может потребовать повторной отправки, а webhook Telegram/Tilda может быть доставлен повторной попыткой. Черновики, ключи отправки и постоянная очередь защищают от потери данных, когда они уже сохранены. Спящий или остановленный процесс не выполняет фоновые повторы; они продолжатся после пробуждения. Бесплатного мгновенного ответа круглосуточно эта схема не гарантирует.

В Render включено 750 часов Free-экземпляров на workspace в месяц, также ограничены трафик и сборки. Не подключайте автоматическое платное расширение лимитов.

Neon Free не имеет 30-дневного срока удаления базы как бесплатный Render Postgres. На момент проверки заявлены 1 GB данных и 100 CU-hours в месяц на проект, compute засыпает после 5 минут простоя. Частый опрос истории при открытой странице, healthcheck и активная очередь расходуют compute: следите за Consumption. При достижении лимита нужна остановка/ожидание обновления лимита либо отдельное решение владельца о платном тарифе. Платный тариф автоматически не включается этим проектом.

Vercel Hobby не выбран: его бесплатный тариф предназначен для личного некоммерческого использования, тогда как senyamarketing.ru привлекает заявки на услуги. Render предупреждает, что Free ориентирован на тесты и хобби, без производственных гарантий. Если задержки пробуждения окажутся неприемлемы, потребуется другой согласованный вариант размещения.
